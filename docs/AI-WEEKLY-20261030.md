## 画面与声音

宋体标题、微软雅黑正文、纸色和海蓝为主色。正文采用两段信息轮换；图形使用原创逐帧SVG，
有电脑操作、算力节点、跨页文档、实验室、来源核验、并行生成、训练流程、安全防御和机器人主题。
片头的三张编辑样页是示意图，画面已标注，不冒充产品截图。横竖版分别排版，来源与字幕保留。
竖屏留出右侧及底部操作余量，是设计选择，不冒称平台固定安全区。

中文旁白在本地生成，复用现有Kokoro隔离环境，speaker3、原生speed1.03、句间0.2秒、每场0.6秒起播。
专名读音覆盖限定在本期，字幕保留原稿；音乐复用原创A Window on Today，本地合成音符，无外部采样。
原日报、综合周报和音频目录继续保留。

## 工程入口与复现

独立模块 `video/effects/ai-weekly/`，音频 `video/public/ai-weekly/`，
Studio合成 `AiWeekly-Bilibili` / `AiWeekly-Douyin`，另有横竖独立分镜，便于调整。
共享排版按本期新闻数和每场时长显示进度及换段点；旧16秒场景保留原节奏和默认样式。

```powershell
cd D:\AI项目\Remotion\video
npm run audio:ai-weekly -- --check
npm run audio:ai-weekly
npm run verify:ai-weekly-content
npm run check:versions
npm run lint
npm run build
npm run verify:ai-weekly-bilibili
npm run verify:ai-weekly-douyin
npm run render:ai-weekly
```

导出脚本使用固定bundle，核对分镜、字幕和音频哈希，导出后检查实际流规格、全片解码及11个真实AAC旁白窗口。
客观RMS、样本峰值、削波数不是LUFS、true peak或自然度评分；静帧与完整解码不等同逐帧人工观看或全片人工听审。
最终验收值在完成后补入下节。
