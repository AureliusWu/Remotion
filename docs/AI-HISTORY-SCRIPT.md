# 从提问到共创：人工智能发展历程

资料核验截至 2026-10-29。旁白、取舍与图形均为本工程原创编排。

## 01 机器会思考吗（从当代问题回到历史起点）

### 01-01 一块屏幕，几个不同的问题

想象一块屏幕上，机器正在辨认照片，接续一句话，又为一盘棋寻找下一步。

这些动作都可能被叫作人工智能，但识别、生成和规划，面对的任务不同。

当回答看起来像人写的，我们容易把语气，当成背后也有同样的体验。

从能力怎样做出来开始，也追问凭什么信任它。

资料：turing1950 / dartmouth1955

### 01-02 把大问题拆成可以检查的任务

机器会思考吗，一句话里藏着许多不同要求。

我们可以让它给图形分类，解释推理题，或者在陌生摆设之间寻找路线。

每添一项要求，都要说明输入是什么，怎样算成功，在哪些情形下会失败。

把问题拆小，没有消除关于心智的争论，却让研究者能拿出证据。

资料：turing1950 / dartmouth1955

### 01-03 答案之外，还要看条件

把一段回答放在画面中央，遮住回答者的姓名、面孔和制作方式。

我们会依据措辞和推理判断，可一次精彩回答，不足以证明所有能力。

问题换一种问法，材料换一个领域，结论是否可靠，还要检验。

机器表现得像人，与它是否拥有人的意识，是两个需要分别讨论的问题。

资料：turing1950

### 01-04 沿着问题，而不是神话前进

这条时间线，将从纸上的计算规则，走向调整参数的网络，也经过写满经验的规则库。

这些路线并非整齐接力，旧方法继续工作，新方法也借用旧问题的答案。

我们会分清论文的设想、实验室的演示和真实环境中的使用。

才能理解突破为何令人兴奋，期待为何落空。

资料：dartmouth1955 / r1_1980 / backprop1986

## 02 让计算与推理拥有形式（1936—1950）

### 02-01 一条纸带上的计算

一九三六年，图灵用抽象机器研究计算：读一个符号，按规则改写，再移动读写头。

纸带不断延伸，复杂任务被拆成有限规则指挥的小动作。

这不是当年造出的智能机器人，而是讨论什么能够被机械计算的数学模型。

它为通用计算提供重要基础，也揭示计算能力存在边界。

资料：turing1936_archive / turing1936_paper

### 02-02 神经元成为逻辑单元

一九四三年，麦卡洛克和皮茨，把神经活动抽象成激活与不激活的单元。

几个输入共同越过门槛，节点才亮起，就能组成某些逻辑关系。

这座桥连接神经系统的启发和形式逻辑，却省略了大量生理细节。

作者研究的是理想模型的计算性质，不能当成大脑已被完整解释。

资料：mcculloch1943

### 02-03 图灵换了一种提问方式

一九五〇年，图灵发表《计算机器与智能》，借模仿游戏重新组织思考的问题。

他把讨论转向文字问答中可观察的表现，并设想机器参与其中。

画面里的提问者只看逐行出现的回答，不能凭声音和外貌识别对方。

抽象争论由此更接近实验，但对话判断仍不是意识存在的证明。

资料：turing1950 / turing1950_archive

### 02-04 执行规则与获得规则

执行写好的步骤，与在经验中改善表现，是相关却不同的问题。

图灵在一九五〇年的论文中，也讨论学习机器，以及从较简单起点进行教育的设想。

画面左边放固定指令卡，右边放随着训练改变的内部状态。

后来反复出现的争论已露轮廓：哪些结构由人设计，哪些从经验获得。

资料：turing1950

## 03 达特茅斯：一个领域得到名字（1955提案 · 1956夏季研讨）

### 03-01 先有一份提案

一九五五年八月，一份夏季研究提案，把人工智能写进标题。

麦卡锡、明斯基、罗切斯特和香农，计划次年夏天到达特茅斯共同研究。

纸面安排约十个人、两个月，讨论语言、抽象、学习等问题。

这记录的是研究计划及其雄心，不能把计划中的目标，写成已经完成的成果。

资料：dartmouth1955

### 03-02 把雄心展开成研究清单

展开提案目录，语言、神经网络、抽象概念和计算规模，并排出现在纸上。

文件提出大胆猜想：智能可以被足够精确地描述，再由机器模拟。

猜想是出发点，需要后续实验和理论检验，并不是已经证明的自然定律。

研究者希望找到共同的问题语言，让不同背景的人交换方法。

资料：dartmouth1955

### 03-03 夏天并没有交出万能机器

一九五六年，夏季研讨确实在达特茅斯举行，却没有交出万能的思考机器。

来访者停留时间不同，工作包含分散研究与讨论，并非全员整齐开会两个月。

日历翻过，桌上留下问题、程序和继续合作的可能。

它凝聚了一个研究方向，而不是让此前所有探索突然从零开始。

资料：dartmouth1955 / dartmouth_history

### 03-04 从名字回到可以运行的工作

有了人工智能的名字，仍要回答具体问题：一句话怎样表示，一步推理怎样搜索。

一条路线写出符号和规则，另一条让简单单元通过连接共同工作。

两条线同时保留，避免把历史看成只有一条道路的直线。

不同方法放大智能的一部分，也省略了当时难解的复杂性。

资料：dartmouth1955 / logic_theory1956 / rosenblatt1958

## 04 感知机与符号推理（1957—1960年代）

### 04-01 让连接随例子改变

一九五七年前后，罗森布拉特提出感知机研究，次年发表详细的理论论文。

它借助输入、连接强度和输出，研究系统怎样在经验中形成分类能力。

两类图案进入网络，连接的粗细随着学习逐渐改变。

与逐条手写识别规则相比，这里出现另一种思路：让训练塑造部分区分能力。

资料：rosenblatt1958 / rosenblatt1957_record

### 04-02 一条会移动的分界线

看一个简化模型：两个输入按权重相加，再与门槛比较，决定输出。

红点被错分，学习规则便调整权重，让分界线向有利方向移动。

这条直线是单层线性分类器的示意，并非所有感知机结构的完整复原。

机器获得某种区分规律，能否迁移到新样本，还要看数据和问题本身。

资料：rosenblatt1958

### 04-03 另一条路：寻找一条证明

一九五六年，纽厄尔、西蒙与肖参与开发的逻辑理论家，探索自动证明。

把命题、规则和待证结论排成节点，程序在推导路径间寻找连接。

启发式方法让它优先尝试有希望的方向，减少无差别遍历。

符号搜索展示了力量，但形式逻辑的证明，并不自动包含生活中的常识。

资料：logic_theory1956 / cmu_logic_history

### 04-04 能力边界开始显形

红蓝点放在正方形的交错角上，一条直线就无法把两类完全分开。

增加结构或改变表示，可能突破这个例子，却带来训练难题。

一九六九年，明斯基和帕普特系统分析一类感知机的能力与限制。

这不等于所有神经网络无效；特定模型的局限，不等于整条路线的未来。

资料：perceptrons1969 / rosenblatt1958 / backprop1986

## 05 会回应的程序，会规划的机器人（1960年代—1972）

### 05-01 伊莱扎怎样接话

一九六六年，魏岑鲍姆发表伊莱扎，展示一种人机语言交流方式。

它寻找关键词，按规则拆开输入，再用重组规则生成回应。

把我感到焦虑，改写为你为什么感到焦虑，是解释机制的中文示意。

这种回应不需要语言模型式训练，也不能证明它理解了说话者的人生。

资料：eliza1966

### 05-02 熟悉的语气怎样影响判断

相同文字，装进普通终端或亲切的聊天窗口，会引导我们怎样判断。

伊莱扎的经典脚本借用心理治疗式问答，把不少话题交还给说话者。

翻开回应下方的规则卡，让观众同时看见语言表面与生成机制。

这里不重演真实用户的情绪经历，而是提醒信任需要超出语气的证据。

资料：eliza1966

### 05-03 沙基把感知、规划与行动连起来

一九六六年到一九七二年，斯坦福研究所的沙基项目，把问题带入实体空间。

移动机器人感知环境的一些特征，规划路线和简单物体的重新摆放。

从一个房间去往另一个位置，需要把目标拆成可执行动作。

依次点亮感知、规划和行动，说明智能系统远不止输出一句答案。

资料：shakey_sri

### 05-04 从整洁房间走向真实世界有多远

给实验房间加上杂乱家具、移动的人和变化的光线，任务就会变难。

这是解释边界的示意，并不是说沙基当时已经能处理这些场景。

受控环境中规划与行动的贡献，应与开放世界的可靠自主能力分开评估。

演示让可能性可见，研究还要回答，哪些条件下能够重复成功。

资料：shakey_sri / shakey_sri_retrospective

## 06 低潮：承诺遇到现实（1966—1970年代）

### 06-01 阿尔帕克评估的具体对象

一九六六年，美国阿尔帕克委员会发布《语言与机器》，评估机器翻译。

报告比较质量、时间、成本与人工参与，对近期实用目标提出质疑。

让文件经过机器、人工修改与交付，画面展示评估应覆盖整个过程。

报告有具体任务范围，不能说成全世界所有人工智能研究被同时叫停。

资料：alpac1966

### 06-02 缩小承诺，继续研究语言

阿尔帕克报告也建议支持语言学和计算语言学基础研究，发展人类翻译的辅助工具。

短期承诺退潮，与研究价值被完全否定，并非同一件事。

缩小全自动翻译的招牌，再把语料、语言分析和辅助工具的灯留下。

交付方式暂时不通，重新界定问题，往往比放大口号更有建设性。

资料：alpac1966

### 06-03 英国的莱特希尔报告与争论

一九七三年，英国科学研究委员会委托的莱特希尔报告，尖锐批评人工智能。

它质疑一些方法扩展规模后，能否应付急增的组合可能性。

搜索树不断分叉，多走几层，就会增加大量需要考虑的路径。

麦卡锡公开反驳，说明这既是资助政策节点，也是学术判断存在分歧的争论。

资料：lighthill1973_archive / mccarthy_lighthill1973

### 06-04 寒冬不是全球统一的停机按钮

后来，人们用人工智能寒冬，概括期待下降、部分资助收缩和项目受挫。

美国翻译评估与英国研究评审，时间、对象和制度环境不同，并非同一份禁令。

让各地温度曲线分别变化，保留仍推进的规划和知识研究。

低潮改变资源与声誉，却没有让所有研究者同时放下问题。

资料：alpac1966 / mccarthy_lighthill1973 / mit_ai_history2019 / r1_1980

## 07 把专家经验写进规则（1970年代—1980年代末）

### 07-01 麦辛：窄领域里的推理

七十年代，斯坦福的麦辛项目，围绕特定感染的诊断和抗菌治疗建议，研究知识推理。

它提问收集病例信息，调用规则形成建议，并说明部分依据。

画面仅用抽象病例卡，不把历史程序包装成医疗意见。

麦辛没有成为日常临床使用的替代医生，实验评价和临床部署必须区分。

资料：mycin1984 / shortliffe2006

### 07-02 规则库让经验可以被检查

专家系统将部分经验写成规则：如果条件成立，那么采取某种判断或动作。

推理引擎沿规则链工作，知识工程师从专家获得知识，整理进系统。

麦辛用确定性因子表示证据支持程度，不能当作校准的概率。

规则连成链，也标出缺失条件：写下经验，仍须核对适用范围。

资料：mycin1984 / mycin1982

### 07-03 从论文走向订单配置

一九八〇年论文记录，阿尔一专家系统已被数字设备公司制造部门经常使用。

后称艾克斯康的系统，根据订单配置计算机部件和连接关系。

发现缺少部件时，它补足订单，并输出装配人员使用的配置图。

机柜和线缆在画面接好：人工智能的价值，也可以是改善具体工作。

资料：r1_1980 / xcon1989

### 07-04 繁荣之后，维护账单浮现

八十年代，专家系统迎来热潮，但获取知识、更新规则和处理例外，都要投入。

加入新部件，相关连接与约束就要检查，规则多并不代表容易维护。

八十年代末至九十年代初的部分商业收缩，常被归入第二次低潮，分期并不统一。

成功应用仍在，局部成功却不能保证普遍兑现。

资料：xcon1989 / expert_brittleness1988 / mit_ai_history2019 / expert_pioneers2018

## 08 反向传播与连接主义回归（回到并行时间线：1986及其前后）

### 08-01 中间那层，应该怎样学

回到一九八六年，并行的另一路线重新受到关注：训练含隐藏层的神经网络。

输入经过中间节点才得到输出，可答案错了，前面的连接应该怎样调整。

把错误标记停在输出端，再展开各层之间的依赖关系。

关键问题是：不能只告诉系统错了，还要找到改善结果的调整方向。

资料：backprop1986 / hinton2014

### 08-02 前向计算，反向求导

反向传播先计算网络预测与目标之间的损失，再反向计算梯度。

链式法则将复杂变化率拆成局部计算，高效求出许多权重的影响。

随后，优化方法根据梯度调整参数，例如小步走向降低损失的方向。

反向流动的是求导信息，不是倒着思考，也不保证找到最好的答案。

资料：backprop1986 / hinton2014

### 08-03 学习的不只是最后一道分界

一九八六年，鲁梅尔哈特、辛顿和威廉斯的论文，展示反传学习内部表示。

隐藏单元能形成有助于任务的特征，不必逐个由人预先写好。

让交错点经过中间层重新表示，再完成分类，这是简化示意。

梯度与训练思想有更早基础，不能将重要论文写成毫无前史的首次发明。

资料：backprop1986 / hinton2014 / hinton_backprop_lecture

### 08-04 方法回归，困难并未消失

反向传播让多层网络训练更有希望，却没让当时的机器立刻拥有今天的生成能力。

数据、计算、网络结构和训练是否顺利，仍影响模型能够学到什么。

学习曲线有时下降、有时停滞，进步需要反复实验。

表示能够随任务改变，但怎样可靠面对更大世界，仍有问题待解。

资料：backprop1986 / hinton2014

## 09 从规则走向统计学习（1990年代）

### 09-01 让样本参与设计

进入二十世纪九十年代，一条重要路线是让机器从样本中学习可重复的关系。

识别手写邮编时，工程师不只列举笔画规则，还收集不同人的字迹，让算法比较预测与答案。

模型调整的是参数，并未经历人的生活。

关键考验是能否认出没见过的字，而不只背下练习。

资料：b-lenet-1998 / b-svm-1995

### 09-02 支持向量机的间隔

一九九五年，科尔特斯和瓦普尼克发表支持向量网络论文。

把两类邮件画成点，算法寻找分界，尽量留下宽阔间隔，也允许对少量错误作出权衡。

核方法可以在另一种特征表示中处理弯曲边界。

这是一种数学分类，并不表示机器理解了发件人的意图。

资料：b-svm-1995

### 09-03 把不确定性放进模型

概率模型不急于给出非黑即白的答案，而是计算在已有证据下，各种解释有多大可能。

比如听含糊的语音，可以把隐藏的发音状态与声音联系起来，比较词序列。

九十年代的概率图模型把变量依赖画成图，并研究近似推断。

结论依然受模型假设约束。

资料：b-hmm-1989 / b-graphical-1999

### 09-04 数据也要接受检查

一九九八年，勒昆等人的论文展示卷积网络与文档识别，神经网络并未从历史中消失。

手写数字让方法有了共同考题，但训练与测试必须分开。

如果样本只来自少数写字习惯，换一批人就可能出错。

数据代表了谁，怎样划分，也与算法一样值得追问。

资料：b-lenet-1998 / b-svm-1995

## 10 专门胜利与视觉转折（1997—2012）

### 10-01 深蓝赢下的是棋局

一九九七年五月，深蓝在六局国际象棋赛中，以三点五比二点五战胜卡斯帕罗夫。

它结合高速搜索、局面评估和棋类知识，在明确规则下完成了专门任务。

但赢棋不会自然带来聊天、看路或照顾孩子的能力。

棋盘内的成就，需要连同边界一起理解。

资料：b-deep-blue

### 10-02 先修建共同考场

识别生活照片时，同一种猫也会有不同姿势、光线和背景，棋盘式规则就不够用了。

二〇〇九年的ImageNet论文，提出按词义层级组织的大规模图像数据库。

研究者搜集、清洗图片，并组织人工标注。

此后的竞赛把任务和评分口径固定下来，让不同算法能够比较。

资料：b-imagenet-2009 / b-ilsvrc-2014

### 10-03 AlexNet的成绩单

二〇一二年，AlexNet方案在图像分类竞赛中取得突出成绩。

论文报告，参赛组合的前五错误率为百分之十五点三，第二名是百分之二十六点二。

前五看的是五个候选类别里有没有正确答案。

这不是现实视觉的总正确率，却推动更多研究者投入深度网络。

资料：b-alexnet-2012 / b-ilsvrc-2014

### 10-04 三种条件相遇

这次转折来自数据、网络方法与计算工具的配合，并不是某个公式突然奏效。

图形处理器并行计算，卷积利用图像局部关系，训练技巧帮助调整参数。

研究更多转向让特征表示参与学习。

但遮挡、陌生场景和错误标签仍会带来困难，成绩需要放回具体任务中解释。

资料：b-alexnet-2012 / b-lenet-1998

## 11 从围棋到注意力（2016—2017）

### 11-01 围棋中的学习与搜索

二〇一六年三月，AlphaGo在首尔以四比一战胜李世石，引发公众关注。

它结合神经网络与搜索，估计值得尝试的落点和局面的胜算。

人类棋谱提供起点，系统还通过自我对弈继续调整。

学习缩小搜索范围，搜索把局部判断放回完整棋局，两者互相补充。

资料：b-alphago

### 11-02 棋盘之外还有距离

围棋有给定的规则、行动范围与胜负反馈，而现实工作常常要先弄清目标。

一次建议面对不同需求，可能带来不同后果。

例如安排日程，不只要找到空档，还要理解哪些约定更重要，哪些决定必须确认。

从封闭棋盘走向生活，需要重新定义任务，也需要新的验证。

资料：b-alphago / b-agi-levels

### 11-03 一句话中的远近关系

二〇一七年的论文提出Transformer架构，最初重点展示机器翻译。

一句长句中，决定词义的线索可能在很远的位置，自注意力让各位置按相关程度交换信息。

这是一种可训练的加权计算，并非人的专注。

它配合位置表示与其他网络层，形成新的序列建模方式。

资料：b-transformer-2017

### 11-04 一种架构，多种任务

Transformer在训练时更容易并行处理序列中的许多位置，便于利用大规模计算。

但架构只是骨架，训练目标决定练习什么，数据决定能接触什么。

同一骨架可以用于翻译、文本表示或生成文字，能力却不必相同。

下一次转折，便在训练目标与海量文本的结合处。

资料：b-transformer-2017 / b-gpt-2018 / b-bert-2018

## 12 预训练与对话入口（2018—2022）

### 12-01 先从大量文本中学习

二〇一八年的GPT论文展示一条路径：先在大量未逐项标注的文本上学习，再适应具体任务。

模型练习根据前文预测后续片段，从中调整词语与上下文的表示。

这样不必为每项任务从零开始。

但预训练并未把文字变成核实过的知识库，迁移效果仍要检验。

资料：b-gpt-2018

### 12-02 从填空理解上下文

同年公布的BERT采用另一种训练思路，同时利用左右上下文学习文本表示。

它遮住句子中的部分词，让模型练习恢复内容，再把表示用于问答或分类。

填空题只是帮助理解的比喻，机器没有经历书中的生活。

不同目标能够练出各有长处的模型。

资料：b-bert-2018

### 12-03 规模化是一条经验规律

二〇二〇年的规模规律研究，考察模型大小、数据量与训练计算对预测损失的影响。

同年的GPT-3展示了在提示中给少量示例，完成多种语言任务的可能。

但经验趋势来自特定实验条件。

不能由此推断参数越多，一切能力就必然更好，数据质量与失败案例仍要检查。

资料：b-scaling-2020 / b-gpt3-2020

### 12-04 对话改变了入口

二〇二二年十一月三十日，OpenAI推出ChatGPT研究预览，让公众通过对话直接试用。

人类示范、回答比较与反馈训练，让系统更容易按指令回应。

愿意配合和回答正确却是两回事。

发布说明就列出了貌似合理的错误输出，便捷界面也让核实信息更必要。

资料：b-chatgpt-2022 / b-instructgpt-2022

## 13 当模型开始生成图像（2014—2022 · 沿另一条线回望）

### 13-01 生成器与判别器

文字之外的生成研究也有自己的路径，把时间拨回二〇一四年，看看生成对抗网络。

一个网络生成样本，另一个区分训练数据与生成结果，两者交替调整。

这像生成与辨别的练习，网络并没有人的动机。

它学习的是数据分布，并不意味着画面真实发生过。

资料：b-gan-2014

### 13-02 从噪声一步步重建

二〇二〇年的去噪扩散概率模型，是另一条图像生成路线的重要节点。

训练时逐步给图像加噪，让网络学习相应的去噪任务；生成时，再从噪声出发得到样本。

画面仿佛从雾中浮现，这是过程示意。

它学习的是图像规律，画面逼真也不能证明所描绘的事件真实发生。

资料：b-ddpm-2020

### 13-03 文字与图像建立联系

二〇二一年的CLIP研究，把图片与文字描述放进可以比较的表示空间。

训练鼓励配对图文更接近，不配对的更容易区分。

之后可以用自然语言描述类别，测试新的识别任务，而不为每类重新收集训练样本。

它本身不是图像生成器，却为图文系统的组合提供了基础。

资料：b-clip-2021

### 13-04 在潜在空间里扩散

潜在扩散论文在二〇二一年预印，二〇二二年会议发表，把扩散计算搬进压缩后的表示。

系统不必每一步都处理完整像素，还能结合文字等条件引导生成。

这改善了计算需求与细节之间的取舍。

创作工具扩大表达空间，也让素材来源与使用责任更加值得追问。

资料：b-ldm-2022 / b-nist-genai-2024

## 14 能力进入现实之后（当代 · 事实资料截至2026-10-29）

### 14-01 把进步落到具体任务

二〇二一年的AlphaFold论文，展示蛋白质结构预测的重要进展，并估计可信程度。

二〇二四年的阿尔法折叠三，将预测扩展到蛋白质、核酸与配体等相互作用的结构。

画面中的序列到结构，是帮助理解的概念示意。

它不是真实折叠过程的模拟，预测也不能替代实验验证。

资料：b-alphafold-2021 / b-chatgpt-2022 / b-alphafold3-2024

### 14-02 一张榜单装不下可靠性

可靠性不是一张榜单：答对考题、应对变化和知道何时不确定，是不同要求。

二〇二五年，深度求索团队探索用强化学习促进推理。

零版本在后训练中仅用强化学习，正式模型则采用多阶段训练。

这些进展不等于可靠性已经解决，准确、稳健、公平与效率仍需分别检验。

资料：b-helm-2022 / b-gpt3-2020 / b-deepseek-r1-2025

### 14-03 平均值也会遮住人

平均成绩不错的系统，仍可能对某些人群表现较差。

二〇一八年的性别阴影研究，检查商业人脸性别分类系统在不同肤色与性别组上的误差。

它研究特定系统和任务，不能代替今天所有人脸技术的结论。

模型卡进一步提倡公开适用范围、评测条件与分组结果。

资料：b-gender-shades-2018 / b-model-cards-2019

### 14-04 计算背后有物理成本

人工智能运行在真实芯片与机房里，训练用电，反复生成答案也持续消耗资源。

研究表明，模型、硬件、任务与供电条件都会影响能耗和排放。

一次实验的测量，不能当成所有提问的成本。

比较要公开边界，也要考虑能否用合适的小模型完成任务。

资料：b-carbon-2021 / b-inference-energy-2024

## 15 把选择交回人的生活（回望与开放的未来）

### 15-01 回到一天里的小选择

回到开场的一天，面对手机建议、工作草稿和屏幕答案，我们可以请它帮忙，也可以要求解释。

人机交互研究强调说明能力与限制，让纠正和退出足够方便。

自动生成的邮件可以先供你修改。

工具越顺手，越要保留确认关键行动的机会，让便利服务自己的目的。

资料：b-human-ai-2019

### 15-02 责任不能留在黑箱里

把人工智能放进组织，意味着有人决定目标、选择数据与模型，并安排哪一步需要复核。

错误影响人的机会时，不能用算法这么判断结束解释。

还要有记录、纠正与申诉路径，让治理和测量贯穿使用过程。

明确谁能发现问题、谁必须回应，责任才不会留在黑箱里。

资料：b-nist-rmf-2023 / b-model-cards-2019

### 15-03 未来需要更好的问题

未来系统会走多远，不能靠流畅对话或漂亮演示判断，还要说明正在比较什么能力。

研究者尝试区分表现深度、任务广度与自主程度。

陌生情境中的可靠性、目标冲突与风险由谁决定，都仍是开放问题。

这条历史没有给出通用智能已经实现的结论。

资料：b-agi-levels / b-nist-rmf-2023

### 15-04 历史继续，由人参与

人工智能的历史连接着数学、硬件与实验，也连接着许多人的劳动。

节省的时间怎样分配，谁能使用工具，谁的经验被忽略，仍要由我们讨论。

模型可以起草问候，但关心谁、是否发送，还是人的选择。

未来不仅由下一次训练决定，也由这样的日常选择逐渐形成。

资料：b-human-ai-2019 / b-nist-rmf-2023
